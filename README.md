# Der singende klingende Adventskalender

Die Besucherseite zum Adventskalender des musiKKlub Schwerin: 1. bis 23. Dezember 2026, jeden Abend um 19 Uhr Musik an einem anderen Ort in Schwerin. Eintritt frei.

Eine statische Seite ohne Cookies, ohne Tracking und ohne fremde Dienste. Die Schriften stehen unter der SIL Open Font License (siehe `schriften/LIZENZ.txt`). Grafiken und Texte gehören dem musiKKlub Schwerin und sind nicht zur Weiterverwendung freigegeben. Karte: © OpenStreetMap-Mitwirkende.
